# Медуха — офлайн-справочник первой помощи (PWA)

Открытый бесплатный продукт-рекомендация (концепция v4): приложение не зарабатывает,
размещается в открытом виде. Android-версия — APK (0 разрешений, без сети в рантайме).

## Установка на iPhone

1. Откройте ссылку в Safari.
2. «Поделиться» → «На экран „Домой"».
3. Иконка «Медуха» появится на домашнем экране; работает офлайн (service worker кеширует
   содержимое при первом открытии).

## Важно

- Информационный офлайн-справочник. Не заменяет обучение, приказы и медицинскую помощь.
  Первая помощь ≠ врачебная помощь. Разделы фельдшера/медика содержат дозировки
  «по протоколу этапа» — до рецензии действующего хирурга считать черновиком.
- Источники и правила отбора контента — в репозитории проекта (карта источников,
  сверка актуальности). Каждый алгоритм имеет источник и правовую рамку.
- Контакт: владелец проекта (GitHub: ArattaRen).
